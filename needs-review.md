Строки с неоднозначным переводом. Формат: файл · msgctxt (если есть) · msgid → выбранный вариант (альтернатива) — причина сомнения.

## 2026-11-07 — перевод frappe/ru.po с нуля (8003 записи)

### Заголовок файла

- В заголовке `frappe/ru.po` нет `Plural-Forms` (и `Language`). Сам заголовок не правился. Сейчас plural-записей в файле нет, поэтому на компиляцию это не влияет, но при следующем обновлении шаблона стоит добавить `Plural-Forms: nplurals=3; plural=(n%10==1 && n%100!=11 ? 0 : n%10>=2 && n%10<=4 && (n%100<10 || n%100>=20) ? 1 : 2);`.

### frappe/ru.po

- `Use % for any non empty value.` → «Используйте % для любого непустого значения.» — Babel ошибочно пометил запись `python-format` («% f» в «% for» принят за директиву). В русском тексте директивы нет, поэтому `msgfmt --check` выдаст ошибку. Варианты: снять флаг `python-format` при генерации шаблона или исправить исходную строку в Frappe. Флаги я не трогал.
- msgid без контекста `Submit`, `Save`, `Delete`, `Create`, `Edit`, `Amend`, `Execute`, `Attach`, `Share` → глаголы «Провести», «Сохранить», «Удалить», «Создать», «Редактировать», «Исправить», «Выполнить», «Прикрепить», «Поделиться» (альт. «Проведение», «Удаление»… для колонок прав доступа) — один msgid используется и для кнопок, и для подписей прав. Выбран глагол, потому что для кнопок он критичен.
- `Read`, `Write`, `Select`, `Report`, `Export`, `Import`, `Print` (без контекста) → «Чтение», «Запись», «Выбор», «Отчет», «Экспорт», «Импорт», «Печать» — сочетаются с глаголами из пункта выше в одной таблице прав. Если смешение глаголов и существительных в Role Permissions Manager мешает, нужен `msgctxt` в исходниках.
- ctx=Number system · `B`, `K`, `M`, `T` → «млрд», «тыс.», «млн», «трлн»; `Ar`, `Cr`, `Kh`, `L` оставлены без перевода — индийская система счисления, в русской локали не используется.
- ctx=Days/Hours/Minutes/Seconds (Field: Duration) · `d`, `h`, `m`, `s` → «д», «ч», «мин», «с» — если контрол Duration разбирает пользовательский ввод по этим суффиксам, перевод может сломать разбор. Проверить в `public/js/frappe/form/controls/duration.js`.
- ctx=Coins · `Change` → «Сдача» — строка из теста `test_translate.py`.
- `Dock`, `Dock Item` и производные → «Док», «Пункт дока» (альт. «Панель приложений») — новый элемент навигации v16, устоявшегося перевода нет.
- `Automation Flow` → «Сценарий автоматизации» (альт. «Поток автоматизации», «Автоматизация») — новый модуль автоматизации.
- `Swimlanes` → «Дорожки» (альт. «Группы», «Полосы») — канбан v2.
- `Reference Document` / `Reference DocType` / `Reference Name` → «Документ-основание» / «Тип документа-основания» / «Имя основания» (альт. «Связанный документ») — терминология 1С. В уведомлениях и ToDo это «связанный документ», а не основание в учетном смысле.
- `Non-Conforming` → «Небинарный», `Genderqueer` → «Гендерквир», `Mx` → «Mx» — значения справочника Gender и Salutation; в русском нет устоявшихся аналогов.
- `Upsert` → «Вставка или обновление» — статус в списке импорта данных.
- Options Permission Inspector · `amend`, `cancel`, `create`, `delete`, `read`, `write`… → «исправление», «отмена», «создание»… — значения Select. Предполагается, что они только отображаются, но если инспектор сравнивает их как строки, перевод безопасен лишь при переводе на клиенте.
- Опции цвета индикатора Workspace (`blue`, `green`, `darkgrey`…) → «синий», «зеленый», «темно-серый» — хранятся по-английски, переводится только отображение.
- `Highlight` (Company History) → «Ключевое событие» (альт. «Главное») — поле страницы «О нас».
- `Drain Seconds` / `Stale Running Minutes` (Automation Settings) → «Секунды на завершение» / «Минут до признания зависшим» — служебные параметры обработчика очереди, точный смысл стоит сверить с документацией.

## 2026-11-08 — повторная вычитка frappe/ru.po

- `After Discard` / `Before Discard` / `Permanently Discard {0}?` / `Discard {0}` → «После отмены черновика», «Перед отменой черновика», «Окончательно отменить черновик {0}?», «Отменить черновик {0}» (альт. «Сбросить», «Отказаться от черновика»). Было «сброс»: это противоречило глоссарию (Discard → «Отменить»), а голое «отменить» совпало бы с Cancel в списке событий серверного скрипта.
- Опции Indicator Color · `gray` / `grey` → «серый» / «серый (grey)» — в Frappe это синонимы, но в одном списке выбора два одинаковых «серый» неотличимы. Альтернатива — оставить оба «серый».
- Scheduled Job Type · Frequency · `Annual` / `Yearly` → «Раз в год» / «Ежегодно» — синонимы в одном списке, поэтому переводы разведены.
